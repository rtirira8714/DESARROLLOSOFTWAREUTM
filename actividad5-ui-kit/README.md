# UI Kit - Sistema Help Desk de Facturación

Este proyecto corresponde a la Actividad 5 de la asignatura Desarrollo de Sistemas Informáticos.

## Descripción

Se desarrolló una biblioteca de componentes visuales reutilizables utilizando CSS3 puro. El UI Kit define la línea gráfica base del sistema Help Desk orientado a la gestión de incidentes relacionados con facturación electrónica.

## Componentes incluidos

- Paleta de colores corporativa mediante variables CSS.
- Botones primario, secundario y de peligro.
- Campos de formulario.
- Selectores desplegables.
- Tarjetas para información de tickets.
- Badges para prioridad alta, media y baja.
- Alertas de éxito, advertencia y error.

## Tecnologías utilizadas

- HTML5.
- CSS3 puro.
- Variables CSS.
- Selectores avanzados.
- Modelo de cajas con `box-sizing: border-box`.
- Diseño responsive mediante Media Queries.
