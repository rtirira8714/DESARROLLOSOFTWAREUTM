Tarjetas para tickets

Prioridad Alta

Error en emisión de factura

El usuario reporta que el sistema no permite generar la factura electrónica después de ingresar los datos del cliente.

Prioridad Media

Problema con firma electrónica

Se presenta una alerta al momento de validar el certificado de firma electrónica dentro del sistema.

Prioridad Baja

Consulta de uso del sistema

El usuario solicita orientación para consultar facturas generadas en días anteriores.
