Bienvenido

Descripción del sistema

Este sistema permite registrar problemas relacionados con la emisión
de facturas, errores del sistema y solicitudes de soporte para los usuarios.

Servicios Disponibles

Soporte para Facturación Electrónica

Realiza el registro de errores durante la generación o emisión
de facturas electrónicas.

Asistencia al Usuario

Encuentra guías, tutoriales y ayuda para utilizar correctamente
el sistema de facturación electrónica.

Seguimiento de Incidentes

Consulta el estado de tus tickets registrados y solicita atención
inmediata y personalizada.
